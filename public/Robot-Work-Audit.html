The 47-Point
Robot Work
Audit Checklist

Every automation opportunity hiding in your workflows — found, named, and ready to eliminate.

"Use this checklist as a walk-through of your week. Work through each section honestly. Every 'yes' is a candidate for automation."
01 Surface the Repetition
  • List your top 10 recurring tasks from the last 2 weeks.
  • Highlight anything you do more than once per week.
  • Flag any task that has the same steps every time.
  • Circle anything that requires copying/pasting between tools.
  • Mark every time you re-type information that already exists somewhere else.
  • Identify every place you "check" something manually (status, inbox, spreadsheet, dashboard).
  • Find every step where you "wait" for someone else (approvals, replies, assets, sign-off).
  • Note every moment you "remind" someone (follow-ups, nudges, pings).
  • List every place you collect the same data in multiple systems.
  • Mark any task that starts with "open X and look for Y."
02 Map the Workflow Anatomy
  • Define the trigger: what event starts it?
  • Define the end condition: what does "done" mean?
  • Write the inputs required (data, files, approvals, context).
  • Write the outputs produced (emails, updates, records, decisions).
  • Identify every decision point ("if this, then that").
  • Identify every exception path ("unless…", "sometimes…").
  • Note where context is lost (handoffs, tool switches, DMs).
  • Identify the source of truth for each key field (name, status, owner, due date).
  • Flag workflows with unclear ownership (everyone/anyone/no one).
  • Flag workflows with unclear SLAs (no time expectation).
03 Classify the Work Type
  • Count how many tools the workflow touches. More tools = more automation opportunity.
  • Find steps that are purely data movement (A → B).
  • Find steps that are formatting/cleanup (renaming, reformatting, resizing, converting).
  • Find steps that are categorization/tagging (labels, folders, properties, statuses).
  • Find steps that are routing (assigning, moving, delegating, escalating).
  • Find steps that are duplication (same message sent to multiple places).
  • Find steps that are aggregation (compile updates, weekly reports, rollups).
  • Find steps that are reconciliation (comparing lists, matching records).
  • Find steps that are scheduling (finding time, sending invites, rescheduling).
  • Find steps that are documentation (meeting notes, summaries, decision logs).
04 Audit Your Communications
  • Locate every recurring message you send (client updates, internal updates, follow-ups).
  • Locate every repeated "explainer" you write (how we do X, FAQs, onboarding).
  • Locate every repeated "ask" you make (requesting assets, approvals, status updates).
  • Find every meeting that exists mainly to share status.
  • Find every meeting output that should be a structured artifact (tasks, decisions, next steps).
  • Identify where meeting notes are taken but not converted into tasks automatically.
  • Identify where action items are created but not assigned or scheduled.
  • Identify where tasks are assigned but not tracked to completion.
  • Identify where deliverables ship but learnings aren't captured.
  • Identify where the same question is answered repeatedly in Slack/email.
05 Find the Automation Opportunities
  • Mark any workflow where the "best next action" is predictable from context.
  • Mark any workflow with high-volume, low-risk decisions (approve, route, archive, label).
  • Mark any workflow where a template could replace free-form work (intake, briefs, reports).
  • Mark any workflow where a form could replace back-and-forth messaging.
  • Mark any workflow where a checklist could prevent errors (handoff, QA, launch).
  • Identify any workflow with measurable success criteria (conversion, response time, cycle time).
  • For each flagged item, write one automation hypothesis.
